# Slot Game

![Gameplay screenshot](./Screenshot%202024-08-30%20083552.png)

Simple slot-machine-style game built with plain HTML, CSS, and JavaScript.

## Overview

This repository contains a lightweight, browser-based slot game. Spin the reels, match symbols, and try your luck. It's designed for learning and demonstration — no frameworks or build tools required.

## Features

- Attractive, responsive UI built with CSS
- Simple game logic implemented in vanilla JavaScript
- Instant feedback on wins
- Easy to read and extend source code

## Files

- `index.html` — main page and game layout
- `styles.css` — styling and layout
- `script.js` — game logic and interactions
- `Screenshot 2024-08-30 083552.png` — gameplay screenshot

## How to run

1. Clone or download this repository.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Edge, Safari).

No server or build step is required.

## Customize

- Edit `styles.css` to change visuals and layout.
- Extend `script.js` to add features like scoring, betting, or animations.
